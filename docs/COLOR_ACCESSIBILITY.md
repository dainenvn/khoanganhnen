# Bảng màu và khả năng tiếp cận (WCAG 2.2 AA)

Bảng màu chính: Navy `#0f172a`, xanh cobalt `#2563eb`, chữ `#334155`, nền `#f8fafc`.

Đã tối màu các điểm kết thúc gradient của thẻ dự án để chữ trắng dễ đọc hơn:
- Project 2: `#075985` → `#0369a1`
- Project 3: `#3730a3` → `#4338ca`
- Project 4: `#064e3b` → `#047857`
- Huy hiệu số dự án: nền navy có độ đục 72% thay vì trắng 20%.
- Vòng focus bàn phím: xanh `#1d4ed8` trên nền sáng, thay màu vàng cũ.

Mục tiêu kiểm tra: văn bản thường >= 4.5:1; chữ lớn >= 3:1; thành phần giao diện và chỉ báo trạng thái >= 3:1 khi áp dụng.

**Chưa tuyên bố toàn bộ trang đạt chuẩn:** cần kiểm tra thực tế bằng axe DevTools, Lighthouse và bàn phím ở các trạng thái hover/focus, độ rộng màn hình khác nhau.
