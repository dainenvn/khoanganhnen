# Các sửa đổi mã nguồn A3

- Xóa thẻ meta description và skip-link bị lặp.
- Thêm id=top để liên kết trở về đầu trang hoạt động.
- Thay 4 liên kết dự án trỏ về chính nó bằng thẻ details/summary có thể mở bằng bàn phím.
- Bổ sung nội dung chi tiết theo từng dự án, phân biệt ý tưởng và chức năng đã kiểm chứng.
- Gộp CSS accessibility trùng lặp, bổ sung style chi tiết dự án và hỗ trợ reduced motion.
- Cải thiện ảnh đại diện tải ưu tiên và văn bản thay thế.
